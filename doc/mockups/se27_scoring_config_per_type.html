Changed from today: the season engine becomes the default; each type card gains an engine selector and names its joined-bracket module; a read-only panel lists the new engine's constants. The EVF value and podium fields keep working: they feed EVF classic and the new engine's 32+ range.

B · The same season after its first scored result

Every field is disabled and a save is refused server-side (ADR-097). The per-type engines are read-only like the coefficients; changing them afterwards needs the audited revision procedure.

C · What it writes

  • Each type's engine is sent as type_engines in the same save the coefficients use (fn_import_scoring_config). The season default stays engine_code.
  • The screen shows each type's resolved engine. A save writes a type's engine only when it changes that type's resolved engine, so resending an unchanged form never pins a type that inherits the season default.
  • Seasons up to 2025/2026 show EVF classic on every type and "Rozdzielenie na kategorie" (PER_CATEGORY_RENUMBER) as the module.
