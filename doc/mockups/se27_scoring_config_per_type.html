Scoring configuration: an engine per tournament type

What changes in the Admin scoring editor (ScoringConfigEditor.svelte) when each tournament type carries its own engine. Everything not shown here — ranking buckets, carry-over, intake thresholds — stays as it is.

What changed in revision 2

1 · PPS and MPS are on EVF klasyczny.

Your change, made in the system as well as on this page: the 2026/2027 assignment is now PPW and MPW on the SPWS engine, and PPS, MPS, PEW, MEW, MSW and PSW on EVF klasyczny. ADR-103 records it as an amendment of 28 September. A PZSz senior field is scored as before ADR-103 — the full field as N and the original place — and still stores K, m and b, which EVF klasyczny does not read. Coefficients are unchanged: PPS × 1.1000 and MPS × 1.3000.

2 · “Is this all there is” for EVF klasyczny?

Of the settings, yes. EVF klasyczny has four adjustable numbers: the base value (50) and the gold, silver and bronze podium coefficients (3, 2, 1), plus each type’s coefficient. Everything else in its formula is fixed by the engine and has no field: the logarithmic place scale, 10 points per elimination round won, and the podium scaling × 3 × ∛N. Revision 1 listed the SPWS engine’s fixed rules but not these; a second read-only panel below now lists them.

The coefficients shown are PROD’s for SPWS-2026-2027, read on 28 September (set on 21 September). CERT still holds the earlier defaults — PPS and MPS 1.0, MEW and PSW 2.0, MSW 1.2 — so the two environments differ until one of them is changed.

A · Season 2026/2027, before its first scored result

Changed from today: the season engine becomes the default; each type card gains an engine selector and names its joined-bracket module; two read-only panels list each engine's fixed rules. The EVF value and podium fields keep working: they feed EVF classic and the new engine's 32+ range.

C · What it writes

  • Each type's engine is sent as type_engines in the same save the coefficients use (fn_import_scoring_config). The season default stays engine_code.
  • The screen shows each type's resolved engine. A save writes a type's engine only when it changes that type's resolved engine, so resending an unchanged form never pins a type that inherits the season default.
  • Seasons up to 2025/2026 show EVF classic on every type and "Rozdzielenie na kategorie" (PER_CATEGORY_RENUMBER) as the module.
  • PZSz (PPS, MPS) is never split, whatever the engine: a result stores the full senior field as N and the original place, plus K = N, m = place and b. Their cards therefore name no module.
