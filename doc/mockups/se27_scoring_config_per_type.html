Scoring configuration: an engine per tournament type

What changes in the Admin scoring editor (ScoringConfigEditor.svelte) when each tournament type carries its own engine. Everything not shown here — ranking buckets, carry-over, intake thresholds — stays as it is.

What changes in revision 3

Only the text that describes the SPWS engine.

ADR-104 replaces SPWS_PLACE_MEDAL_V1_2026_2027 with SPWS_EVF_JOINED_V1_2026_2027. The screen keeps its layout, fields, selectors and lock behaviour. Four texts change, highlighted like this below:

  • the engine's read-only panel: EVF for everything of 4 or more, the premium for older categories in a joined bracket of 4–15, and the 1-point cap;
  • the season default's label, which is the new engine's registry label;
  • the PPW and MPW module line: the bracket's category order is stored, not K, m and b;
  • the hint beside the EVF base value, which now feeds every bracket of 4 or more on every type.

Section C loses the PZSz K, m and b sentence, because those columns are dropped. The engine's constants (the meeting up to 3, the premium up to 15, 5% per step, the 1-point cap) have no field: they belong to the engine version, like EVF klasyczny's.

The coefficients shown are PROD’s for SPWS-2026-2027, read again on 30 September. CERT still holds MEW 2.0, MPS 1.0, MSW 1.2, PPS 1.0 and PSW 2.0. PROD’s values are the intended ones (decision D4); CERT is aligned through this editor on your go, before the release.

A · Season 2026/2027, before its first scored result

Changed from today: the season engine becomes the default; each type card gains an engine selector and names its joined-bracket module; two read-only panels list each engine's fixed rules. The EVF value and podium fields keep working: they feed EVF classic and every bracket of 4 or more on the new engine.

C · What it writes

  • Each type's engine is sent as type_engines in the same save the coefficients use (fn_import_scoring_config). The season default stays engine_code.
  • The screen shows each type's resolved engine. A save writes a type's engine only when it changes that type's resolved engine, so resending an unchanged form never pins a type that inherits the season default.
  • Seasons up to 2025/2026 show EVF classic on every type and "Rozdzielenie na kategorie" (PER_CATEGORY_RENUMBER) as the module.
  • PZSz (PPS, MPS) is never split, whatever the engine: a result stores the full senior field as N and the original place. Their cards therefore name no module.
