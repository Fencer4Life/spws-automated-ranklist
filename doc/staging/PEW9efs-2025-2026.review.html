A category tag in the name

This FTL page writes each fencer's category into the name: “KORONA Przemyslaw (V2)”. The parser stripped “(1)” and a mid-name digit but not a lettered “(V2)”, so the first staging kept the tag in the scraped names and wrote six aliases carrying it (“GAJDA Leszek (V3)” and five more). The parser now strips the lettered form (FTL.NAME.01, failing first); the six aliases are removed, the run discarded and the event staged again with plain names.
