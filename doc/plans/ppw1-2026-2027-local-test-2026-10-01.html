PPW1 2026/27 on the new scoring engine

The real I Puchar Polski Weteranów (Opole, 26–27 September) imported from FencingTime Live into LOCAL with SPWS_EVF_JOINED_V1_2026_2027. Every stored score was recomputed independently with the spec’s reference implementation (A14) and compared.

Verdict

Everything the engine stored is what the rule says

All checks pass. For each of the 102 results, the method, place points, DE bonus, podium bonus, premium, cap reduction, category steps (d) and final score match the reference implementation to the cent. No cap was broken: in every joined bracket each fencer scores at least 1 point less than the fencer placed directly ahead.
  • Import: 14 FTL listings filed as 25 category tournaments; 3 pool-only rounds skipped by schedule; 0 faults, 0 refusals (every fencer had a category, no repeated places).
  • Category order: each listing stores one digit per place; its tournaments hold exactly as many rows as their category has digits.
  • Methods: joined brackets of 4–15 → EVF_JOINED (the youngest category with d = 0, no premium); single categories of 4 or more → EVF_CLASSIC. No bracket had 16 or more, and none had 3 or fewer.
  • Settings used: mp 50, podium 3 / 2 / 1, PPW coefficient 1.0, the same as the reference.
  • Ranking: the scores reach the 2026/27 PPW ranking (for example épée men V1: SĘKOWSKI Maciej 116.14, KORNAŚ Jarosław 84.07, STOCKI Piotr 57.96).

What this event did not exercise

  • The cap never applied. No premium lifted anyone to within 1 point of the fencer ahead, so every cap reduction is 0. The cap path is proven by the pgTAP Part C orders, not by this event.
  • No meeting of 1–3 and no bracket of 16+. The 3-2-1 rule and the 16+ rule were not hit.
  • No refusal. Nobody lacked a category and no joined listing repeated a place.

LOCAL now

What changed on LOCAL

The 2026/27 season on LOCAL now holds scored results, so its configuration is locked on the joined engine (ADR-097), which is what the release does on CERT and PROD. PPW1-2026-2027 carries the FTL link and status IN_PROGRESS. The staging reports are in doc/staging/PPW1-2026-2027.20261001-044227Z.md and .diff.md, untracked. To run it again: the same command with --replace. To start LOCAL clean: ./scripts/reset-dev.sh.
