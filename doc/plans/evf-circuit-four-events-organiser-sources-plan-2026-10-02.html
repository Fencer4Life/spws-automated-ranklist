✓ How far EVF’s results can be trusted as a check

For the 13 repaired events EVF covers, 401 of 413 committed results carry exactly EVF’s place, N and points. The 12 others follow from two of your rules: EVF counts fencers who did not start or did not finish in N, and EVF does not close up the places below a fencer who withdrew during the direct elimination. That is why EVF is the check, not the source.

Tests first · RED before GREEN

The work

  1. Ophardt event page. A parser for /{lang}/{id}-{year}/tournament/ that lists each competition with its weapon, gender, category (O40 → V1, O50 → V2, O60 → V3, O70 → V4) and its /results/ page. Tests OPH.EVT.01–04 on saved copies of the three tournament pages: all 16 competitions, the category mapping, a team or combined competition left out, an unknown age band refused rather than guessed.
  2. d’Artagnan event page. The runner sends a d’Artagnan index.html to the existing parse_dartagnan_event_index and reads each competition’s rankings page with that competition’s weapon, gender and category. Tests DART.EVT.01–02 on a saved Salzburg index: the single-category competitions, and the index never read as a bracket.
  3. Runner routing. fetch_event_url_with_skips expands both event pages the way it expands Engarde and 4fence, each bracket filed under its own source category (ADR-105). Tests INTL.EVT.01–02.
  4. Event links on LOCAL. Written by set_event_source_urls, which already reads Ophardt and d’Artagnan pages and writes only when date, name and weapons match the event.
  5. Stage the four on LOCAL and review. One review page, same layout as the 14: what the rule adds and removes, place and N changes, PENDING rows with a recommendation each, and the EVF cross-check (compare_evf_points) with every difference explained.
  6. Your sign-off per event, then the commit on LOCAL, and an override file for any linked or excluded row (fencers named, never numbered).
  7. Release through the integration checkout, scripts/preflight.sh exit 0 first.
  8. CERT, then PROD. The event links set with a scoped update that returns what changed; then each event through phase5-event-runner.yml, one at a time, machine-checked against LOCAL before and after its commit.
  9. Seed refresh from PROD once all international events of 2024/25 and 2025/26 are repaired (ADR-036: the full suite passes before the seed pointer moves). It also brings PROD’s two birth-year corrections, STOCKI and STAŃCZYK, to LOCAL and CERT.
