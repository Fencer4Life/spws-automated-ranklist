Why it is hidden

One season setting, false everywhere

The ranklist shows the switch when the season is published FULL and its scoring config has the flag on — frontend/src/App.svelte:671:

showEvfToggleRanklist = isFullPublication && (scoringConfig?.show_evf_toggle ?? false)

Read today on all three environments: every season has bool_show_evf_toggle = false; 2026/27 is FULL with default mode RANKING. The flag became the ranklist’s own setting, default off, in June 2026, when SPWS lost its national-team selection privilege. FR-34 and FR-64 describe exactly this setting, and its Admin checkbox is „Pokaż przełącznik +EVF/Kadra na Liście” in the season edit form.

✓ The lock does not get in the way

ADR-097 applies show_evf_toggle regardless of the season’s scoring lock (pgTAP SS26.LOCK.07), so the switch can be turned on before or after the first 2026/27 result is scored. The default mode, which is locked, is not touched.

How the flag is written on CERT and PROD

A · I write it, scoped and proven recommended

Through scripts/cloud-sql.sh: read the row first, then UPDATE tbl_scoring_config SET bool_show_evf_toggle = true WHERE id_season = (SELECT id_season FROM tbl_season WHERE txt_code = 'SPWS-2026-2027') RETURNING …, then confirm through the public fn_export_scoring_config and the page itself. It is the same single write the Admin save makes for this flag, and it needs no MFA session from you.

B · You tick it in Admin

Admin → Sezony → SPWS-2026-2027 → tick „Pokaż przełącznik +EVF/Kadra na Liście” → Zapisz, on CERT and on PROD. I check each afterwards.

Undo is the same write with false.
