How it was measured

Method

  • What was photographed: the production custom-element bundle (vite build --config vite.config.ce.ts, what GitHub Pages and WordPress load), built twice: from the branch's starting commit 891e1740 and from the finished code. Playwright's Chromium answered the pages' requests from each build; no server ran and no database was read or written.
  • Data: 76 invented fencers with your screenshot's totals (épée 47, foil 19, sabre 25), one invented event; date fixed at 17 Nov 2026.
  • Stable images: software drawing with fixed settings, each image taken when two consecutive screenshots agree, cropped on whole pixels 8 px outside the card. Two captures of the same code came out identical in all 56 images, and the build-based before-set is identical to an earlier dev-server before-set in all 56.
  • Narrowed states: compared inside the card, the before-image's rows against the after-image's rows 44 px lower, from the bottom up, allowing anti-aliasing of up to 24/255. Every pair matches up to exactly where the filters end.

Tools, kept for the release check: entry-list-tiles-follow-filters-sheet/tools/ (capture.cjs, fixture.cjs, pixdiff.cjs, listcheck.cjs, this generator). Raw results: entry-list-tiles-follow-filters-sheet/diff.json, entry-list-tiles-follow-filters-sheet/listcheck.json, entry-list-tiles-follow-filters-sheet/after/measures.json.
