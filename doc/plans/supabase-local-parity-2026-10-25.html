§ 4 · this Mac

Where the CLI comes from now

  • supabase on PATH is 2.116.0, installed with npm install -g supabase@2.116.0, as CI’s setup-cli installs it.
  • Homebrew’s 2.84.2 is unlinked, not removed; brew link supabase would bring it back, and the new gate would then fail.
  • Every CLI call prints “A new version of Supabase CLI is available: v2.122.0”. That is expected: the pin is deliberate, and ci.yml says why. Moving it is a stack change, tested on a pull request.
  • The integration checkout uses the same CLI and the same LOCAL stack, so its preflight runs this gate too.
