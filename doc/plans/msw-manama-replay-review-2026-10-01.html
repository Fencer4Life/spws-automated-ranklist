Found and fixed during the replay

Four more defects, now built into release 2

  1. Team brackets were ingested as individual results. FTL lists "Vet Team Men's Épée" and similar next to every Vet-40 bracket. The discovery filter kept them, they defaulted to V1, and a team row named "POL" was matched to a fencer. Team brackets are now skipped at discovery (INTL.SCHED.01).
  2. Duplicate codes were merged and N recounted. _consolidate_duplicate_codes merged each team bracket into its Vet-40 namesake and set N to the merged Polish rows (LIPKOWSKA 19th of "1"). For an international event it now refuses to merge two source brackets into one code (INTL.DRAFT.04).
  3. Stage 0 created every participant of MSW events. Its international skip read the organiser from the code prefix, and IMSW/IMEW are "unknown". It is now keyed on the tournament type (INTL.S0.01), as are the POL filter and the V0 check.
  4. That earlier staging run (19:24 UTC, before this session's context was compacted) had polluted LOCAL. It created 911 foreign fencers and wrote foreign names as aliases onto 53 Polish fencers, for example "ROBINSON Lee" onto DROBIŃSKI Leszek and "BUSH Joshua C." onto BOBUSIA Jarosław. My first two replays added 256 more fencers. All of this is undone on LOCAL: the 1,167 unreferenced fencers are deleted, and the 53 alias lists are restored from the audit log. LOCAL is back to the seed's 367 fencers. CERT and PROD were checked read-only and carry no such alias.
