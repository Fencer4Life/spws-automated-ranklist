03 · How (E1 A)

One linking step for workers and the integration checkout

  1. The linking loop and the info/exclude entries move out of seed_worktree() into link_shared(target, primary), which returns the paths it linked. seed_worktree() calls it, so a new worker gets exactly what it gets today.
  2. start() calls it for the registered integration checkout on every session start, when one is registered and it is not the primary. Nothing is replaced: a path that exists, or a link even when broken, is left as it is.
  3. When it links something, the report gains a line: "Integration checkout: linked .env, tools/docs-search/.env from the primary." Nothing is said when there was nothing to link.
  4. A failure there adds a note and never stops the session, as the rest of the hook does.
