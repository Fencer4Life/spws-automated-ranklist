„Zawodniczka” on the women’s list

In Polish, the ranklist says „Zawodnik” when Mężczyźni is selected in the gender dropdown and „Zawodniczka” when Kobiety is selected. English keeps „Fencer” for both. The drill-down follows the same rule.

1 · The rule, as I understood it

The gender dropdown decides the word

LanguageMężczyźni / Men selectedKobiety / Women selected
PolishZawodnikZawodniczka

The word follows the dropdown, not the gender stored for each person. The drill-down opens from the list on screen, so it uses the same dropdown value.

2 · Decide this first

Four decisions, each with a recommendation

D1 The drill-down: change the download button’s tooltip

The drill-down never shows the word „Zawodnik” on screen. The only place it appears is the tooltip of the ODS download button: „Pobierz arkusz ODS z wynikami zawodnika”. If you meant a different phrase in the drill-down, name it.

A (recommended) — the tooltip follows the dropdown: „…z wynikami zawodniczki” for Kobiety.
B — leave the tooltip as it is.

D2 The season rules box (the pill under the list)

Three phrases use the masculine form: „w szczegółach zawodnika” (singular), „Zawodnicy, którzy wystartowali…” and „o liczbę zawodników na tym miejscu” (plural). The box describes the season’s rules for all lists. Its header already says „w każdej broni, płci i kategorii”.

A (recommended) — leave the box as it is. It covers every gender, and the masculine plural is standard Polish for a mixed group.
B — change only the singular „w szczegółach zawodnika/zawodniczki”, following the dropdown.
C — all three phrases follow the dropdown.

D3 The “N” wording in the drill-down

The footer reads „N — liczba uczestników”, and the drill-down spreadsheet has the column „Liczba zawodników (N)”. Under ADR-034, a woman who fenced in a men’s tournament because the event had no women’s bracket keeps that result on the women’s list. For that row, N counts men as well, so „liczba zawodniczek” would be wrong.

A (recommended) — leave both as they are.
B — both follow the dropdown.

D4 The registration form

The registration form has its own gender field (step 1) and five messages with the masculine form (see §3). It is a different screen with no ranklist dropdown.

A (recommended) — not part of this change. If you want it, it becomes a separate task with its own rule: follow the gender chosen in the form.
B — include it here.

5 · How

Same mechanism as the Polish plurals

Wording already varies by key: the season rules box picks sr_best_one, sr_best_few or sr_best_many by number. Gender works the same way. A new key with the suffix _F holds the women’s form. The component picks it when the dropdown says F. t() (ADR-005) does not change.

FileChange
frontend/src/lib/locales/pl.jsonadd col_fencer_F „Zawodniczka” and ods_tip_drilldown_F
frontend/src/lib/locales/en.jsonthe same two keys with the existing English text. The parity test requires both files to have the same keys.
frontend/src/components/RanklistTable.sveltenew optional prop gender (default 'M'). The header uses col_fencer_F when it is 'F'.
frontend/src/components/DrilldownModal.sveltethe same prop. The ODS tooltip uses ods_tip_drilldown_F when it is 'F'.
frontend/src/App.sveltepasses gender={filters.gender} to both. The WordPress ranklist (RanklistElement) wraps App.svelte, so PROD gets the same change.

Nothing else on screen changes. „Zawodniczka” is three letters longer than „Zawodnik”, so the before/after sheet (§7) also checks the header at phone width.
