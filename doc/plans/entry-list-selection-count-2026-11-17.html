The "Wyczyść filtry" link

  • Where: right-aligned, directly under the three dropdowns, above the list.
  • When: only while the search box or any dropdown narrows the list. Unfiltered, it is absent and the form is identical to today.
  • What it does: empties the search box and sets weapon, category and gender back to "--" in one tap. The tiles return to the plain totals; the frame and the highlights go.
  • Cost: when it appears, the list moves down by one short line; it moves back when the link goes.

The rules the mock follows

How the search box joins the filters

  • One selection, four inputs. A fencer is in the selection when they pass the search text and the weapon, category and gender dropdowns. The tiles count the same rows the list shows.
  • Nothing narrowing: today's form. Plain totals, no frame, no highlight, no clear link.
  • Anything narrowing: every tile reads "selection z total" ("of" in English), the yellow frame appears, and the narrowing controls are highlighted.
  • Search reacts on every keystroke. Spaces alone do not count as a search.
  • No match: the tiles read "0 z 76" and the list shows the existing "Brak wyników dla wybranych filtrów."
  • Weapon tiles count fencers. With Szpada chosen, the Floret tile shows the épée fencers who also entered foil, and the Floret and Szabla tiles are dimmed. Dimming follows the weapon dropdown only; the first tile never dims.
  • Language switch: filters and search text stay as they are when the language changes; only the labels change.

Found while reading the code

Issue 1: the search does not fold Polish letters

1 × Typing "zak" does not find ŻAK today

EntryList.svelte compares with toLowerCase().includes(). A visitor without Polish keys cannot find ŁOŚ, ŻAK or ĆWIK. With live tiles the wrong "0 z 76" would be on display.

Fix, in this same change, test first: fold both the typed text and the names before comparing (strip accents, plus ł→l). The mock already does this. There is no folding helper in the frontend yet, so one small function is added in frontend/src/lib/ with its own tests.

Noted, not changed: the placeholder says "Szukaj nazwiska…" while the search also matches first names.
