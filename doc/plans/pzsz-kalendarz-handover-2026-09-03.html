05Traps that cost real time to rediscover

Each of these was measured against the live source on 3 September 2026. Every one of them fails silently if you get it wrong — no exception, no error, just wrong data.

TrapWhat actually happens
The 70-row capEvery broad query returns exactly 70 rows, truncated, no pagination. The default view renders descending and its earliest row is 14.11.2026 — so reading it loses all three round I events. Treat any 70-row response as truncated and raise.
Season is pagination, not truthSezonAutocomplete only exists to get under the cap. Membership is decided by our own tbl_season window. Query the season keys the window touches — {2025/2026, 2026/2027, 2027/2028} — union, then date-filter.
Unknown season keyReturns 0 rows, not the unfiltered 70. Verified on 2027/2028. This is what makes running a year ahead safe.
Percent-encodingSeniorzy (S) needs %28S%29 or the filter no-ops to 70. A raw ó returns 0. Use the ASCII-safe Puchar Polski senior / Mistrzostwa Polski senior — matching is case-insensitive substring, and juniorów does not match.
Corrupt datesId 4307 carries an end date of 11.05.0251. Reject out-of-range years loudly; never write one to dt_end.
Invitation URLs have no extensionEVF finds invitations with href.endswith(".pdf"). PZSz serves /test/fileDownload.php?fileId=…. Anchor on the labelled Komunikaty organizatora section instead.
F is foilGender-split rounds use W/M, not the project's usual M/F: PPS4Fe sits one case-fold from PPS4fe in a scheme whose trailing lowercase run is the weapon list.
Pending promotes get cancelledGitHub cancels an already-pending job when a new one queues in the same concurrency group. Without queue: max on every member, the PZSz promote dies silently — cancelled is not failed, so nothing alerts.
Deadline regexes yield nothingHARVEST_DEADLINE = False in evf_calendar.py:294 records 0/13 on EVF. PZSz measures 0/7. Ship it off.
No registration link exists0/7 komunikaty carry one; entry is club-mediated through the login-walled System Sorga. Leave url_registration NULL — a non-empty value lights the tile's registration dot and would tell a fencer they can enter when they cannot.

06Environment facts

  • .venv at the repository root has pypdf installed — needed for the komunikat parsing. The system Python does not, and there is no pdftotext on this machine.
  • python/tools/_backends.py exists but is framed for one-shot tools and has no retry. It is not the right base for a scheduled workflow — hence the _supabase.py extraction in step 4.
  • All four target columns already exist on tbl_event — url_invitation, url_registration, dt_registration_deadline, txt_venue_address — from 20260326000001_event_schema_extension.sql. Only id_pzsz_event is new.
  • The plan's queue: max claim rests on current GitHub documentation. If the runner rejects it, that is a workflow validation error on the first run — loud and immediate. The fallback is a 15-minute stagger.
