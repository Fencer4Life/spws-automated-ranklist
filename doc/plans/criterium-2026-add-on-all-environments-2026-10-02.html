The 2026 Paris Criterium is missing everywhere

EVF scored the Criterium Mondial Vétérans 2026 (Paris, 4–6 July 2026, 399 fencers, 10 Polish results), and it falls inside 2025/26. LOCAL, CERT and PROD have no event for it, so its results are in no ranking, and 2025/26 results carry into 2026/27. This plan adds it on all three environments, from the organiser's Engarde results, checked against EVF's record. It also fixes how CERT and PROD receive any repaired event, which the repair batch needs too.

The release push failed CI; nothing is deployed

Pushed 647f5a2d to main. CI's pgTAP job failed while loading the seed, before any test ran, and the Release workflow runs only after a green CI, so CERT and PROD are unchanged.

Cause. The new type guard (TT.CODE, migration 20261002000003) maps the code family DMEW to MPW, copied from derive_tourn_type_from_event_code, which routes the team championship to the MPW threshold. The seed (seed_prod_latest.sql, 12 September) still holds six bracket stubs of DMEW-2025-2026 typed MEW. CI applies migrations before the seed, so the guard refuses the first one. LOCAL passed because its database was not rebuilt and the guard checks writes only. CERT and PROD hold no DMEW tournament today (the event is PLANNED, with 0 tournaments), so the mismatch exists only in the seed.

T How DMEW is typed

  • A the guard leaves DMEW unmapped: it checks every other family and says nothing about DMEW until its type is decided. Seed loads, nothing else changes. One-line migration fix plus a test pinning it.
  • B DMEW is MEW in the guard and in derive_tourn_type_from_event_code; ADR-066 threshold routing for the team championship then moves from MPW to MEW.
  • C DMEW stays MPW everywhere, and the six stale stubs are removed from the seed.

Recommendation: A. It unblocks CI without deciding what a team championship scores as, which no stored result depends on today. B and C each change a rule or the seed beyond this fix.

✓ Decided 2 October: A

DMEW is the team European championship, held every two years; IMEW, the individual one, in the other years. DMEW is never scraped for the ranking (ADR-021: SPWS does not track team results), so it holds no tournament and its type is never used. The guard leaves it unmapped (TT.CODE.09, failing first). All 879 seed tournament rows now pass the guard; the six DMEW stubs leave the seed with its next refresh from PROD, which holds none.

Why it is missing

No path created it

  • The 2024/25 edition came from the initial spreadsheet import (its slug is the Engarde name, crit25; it is in the first PROD seed of 12 April 2026), not from the EVF calendar sync.
  • The 2025/26 events came from the season generator, which has no Criterium entry, and from the EVF calendar sync, which reads EVF's public calendar list and never created it.
  • Nothing compared the season with what EVF actually scored. A scan of EVF's results API for 2024/25 and 2025/26 now does: every EVF event with results has a row except the Criterium 2026 and Chania 2025 (decision K). Event 83 (17 May 2026) has no results at EVF.
  • 2026/27 has no Criterium either, and its PEW10 is Lausanne. The completeness check below flags the 2027 edition once EVF builds it.
